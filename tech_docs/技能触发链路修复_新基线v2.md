## 2. 缺陷清单（按严重度）

### P0-1　技能索引在非首轮恒空 —— 缓存哨兵用 `""` 与"空结果"不可区分
`skills/manager.py:270-271`
```python
self._index_prompt_cache = ""
self._index_prompt_cache_compact = ""
```
`skills/manager.py:519-522`
```python
if hasattr(self, cache_key):
    cached = getattr(self, cache_key)
    if cached is not None:      # "" is not None → True
        return cached           # 首次调用即返回 ""
```
调用侧 `agents/core.py:910-915`
```python
if is_initial and query:
    skill_index = skills.get_index_prompt(compact=False, query=query)  # 正常
else:
    skill_index = skills.get_index_prompt(compact=not is_initial)      # 恒空
```
**后果**：除"首轮且带 query"外，所有请求（第 2 轮起、heartbeat、cron、续跑、无 query 首轮）
`[AVAILABLE SKILLS]` 段**完全不注入**——模型看不到任何技能，只能靠场景强制段。
`invalidate_index_cache()` 同样写 `""`，语义上"清缓存"与"缓存了空"无法区分。
**修法**：哨兵改 `None`，判定改 `if cached is not None`（保留）+ 初始化 `None`；
`invalidate_index_cache` 写 `None`。约 6 行。

### P0-2　中文查询触发全量兜底
`match_skills_by_query` 三级：`_TRIGGER_MAP`（54 条，中文仅 1 条）→ 描述词匹配
（`query_lower.split()` 按空格分词，中文整句成一个词，`len(word)>=3` 且要求整词出现在描述里）
→ **无匹配则返回全部启用技能**。
实测 3/6 中文查询落到第 3 级返回全部 19 技能。
**后果**：`get_index_prompt(query=…)` 的按需过滤失效，索引退回全量；且"按需加载"名存实亡。
**修法**：技能声明的 `trigger_keywords` 并入匹配表（见 P1-1）；第 2 级对中文做字符级/
二元组匹配（CJK bigram）；第 3 级兜底改为"返回场景技能+always_load"而非全量。

### P1-1　双轨关键词来源不一致（结构性）
- 提示层 `SkillManager`：只用硬编码 `_TRIGGER_MAP`，**完全不读** SKILL.md 的 `trigger_keywords`
  （`_load_skill` 只取 name/description/index_hint/tags）
- 加载层 `SkillSelector`：读技能声明触发词，239 关键词（12.6/skill）
**后果**：技能作者维护的中文触发词只影响"加载哪些"，不影响"模型看到哪些"；两轨可给出矛盾答案。
**修法**：`_load_skill` 读 `trigger_keywords`（复用 `SkillSelector._extract_frontmatter_keywords`
的读取逻辑），`match_skills_by_query` 第 1 级改为「技能自声明词 ∪ 硬编码别名表」。

### P1-2　query 缓存 key 用 `hash(query) % 10000` —— 哈希碰撞串台
`manager.py:522`。10000 桶，按生日悖论约 120 个不同 query 即 ~50% 概率碰撞；
实例是 workspace 级（`workspace.py:877` factory），同一用户多会话共享 →
一个 query 会拿到另一个 query 的技能索引。
**修法**：key 用 query 原文（或 `hashlib.md5(query)` 全宽），并给缓存加容量上限（LRU）。

### P2-1　`patterns` 正则被当字面量关键词
`skill_selector.py:85` `for key in ("keywords", "patterns", "intent_hints")` 一律 `str(v)` 入索引。
实测 4 技能 22 条（pptx/xlsx/docx/pdf），这些串永不命中，白占索引体积。
**修法**：`patterns` 走正则匹配通道（`re.search`），不进字面量关键词表。

### P2-2　触发句缺失 16/19
索引行退化为"文件描述"而非"触发场景"。B8 已有 `missing_trigger_skills` 告警，数据未修。
**修法**：补 `index_hint`（数据活，逐技能写）。
