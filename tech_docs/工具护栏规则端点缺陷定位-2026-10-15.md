## 1. 直接根因：唯一可达的端点读了一个不存在的键

线上唯一注册并命中的处理器是 legacy 版：

`server/coapis/app/routers/tool_guard.py:325-330`

```python
@router.get("/config/security/tool-guard/builtin-rules")
@require_permission("security:read")
async def get_builtin_rules_legacy(request: Request) -> List[Dict[str, Any]]:
    """Legacy: Get built-in rules (redirects to unified rules)."""
    data = _load_yaml_config()
    return data.get("rules", [])
```

`system/tool_guard.yaml` 顶层键实测：

```
['version', 'description', 'access_control', 'commands', 'evasion_checks', 'global_rules']
'rules' key present: False
```

→ `data.get("rules", [])` **恒为 `[]`**。docstring 写着 "redirects to unified rules"，实现里没有任何重定向。
**这不是回归，是从写下那天起就没通过过。**

---

## 2. 真源实现是死代码（为什么"启用它"这条路走不通）

真源实现存在且正确：

`server/coapis/app/routers/config.py:819-843` → `load_rules_from_directory()` → 实测 **28 条**
（`TOOL_CMD_DANGEROUS_MV` / `TOOL_CMD_FS_DESTRUCTION` / `TOOL_CMD_DOS_FORK_BOMB` …）

但它**永远不可达**，两道门都关着：

1. `server/coapis/app/routers/__init__.py:119`
   `# router.include_router(config_router_internal)  # Disabled: ...` —— 主挂载被注释禁用
2. 唯一会挂载 `config.py` 的是 agent-scoped 路由（`agent_scoped.py:96-135`，prefix `/agents/{agentId}`），
   而 `_app.py` 里**从未调用** `create_agent_scoped_router()`（grep 仅命中 middleware 导入）
   → 实测 `/api/agents/default/config/...` = **404**

结论：28 条规则的实现是死代码；线上可达的 builtin-rules 只有恒空的 legacy 版。

## 3. 结构性根因：两套引擎 + 两套配置源 + 控制台只接了半条链

| 维度 | 旧引擎 `ToolGuardEngine` | 统一引擎 `UnifiedToolGuardEngine` |
|---|---|---|
| 规则来源 | `security/tool_guard/rules/dangerous_shell_commands.yaml` = **28 条**；custom/disabled 来自 **config.json** | `system/tool_guard.yaml` = **125 commands + 8 global_rules + 11 evasion_checks** |
| 运行时接入 | `agents/tool_guard_mixin.py:109-112` → `engine.guard()`、`is_denied()`(408)、`is_guarded()`(569/611) | `agents/tool_guard_mixin.py:478-488` → `process_command()`（**仅 shell**）；`sandboxed_executor.py:67-72` |
| 开关来源 | env `COAPIS_TOOL_GUARD_ENABLED` > config.json `security.tool_guard.enabled`（实测 enabled=True, guarded_tools=None） | **代码里没有任何 `enabled` 引用**（grep 0 命中） |
| 控制台写入 | **无**（config.py 的 PUT 未挂载） | `tool_guard.py:306` PUT 写 YAML `access_control.*` |

### 三条"写了不生效"（逐条实证）

1. **开关无效**：`PUT /config/security/tool-guard` 写 YAML `access_control.enabled`
   → 统一引擎不读 `enabled`；旧引擎读 config.json/env，不读 YAML
   → **两边都不生效**（实测 YAML `access_control.enabled: True`，config.json `enabled: True`，互不相连）
2. **自定义规则无效**：同一 PUT 写 YAML `custom_rules`
   → 旧引擎的 custom rules 从 **config.json** 读（`guardians/rule_guardian.py:537-548`）
   → 统一引擎 `_compile_rules()` 只编译 `global_rules`（`unified_engine.py:491-507`），**不碰 custom_rules**
   → 写进去没人读
3. **纯假接口**：`GET/PUT /config/security/shell-guard/rules`（`tool_guard.py:333/341`）读写 YAML `rules` 键
   → GET 恒 `[]`；PUT 返回 `{"status":"saved"}` 但统一模型 `ToolGuardConfig` 无该字段 → 静默丢弃

（正向确认：`_save_yaml_config()` 会 `reset_engine()` 清统一单例，所以 commands/global-rules/evasion 的修改**是生效的**，`_reload_engine()` 这个 helper 定义了但没人调用——死函数。）

## 4. 影响面

- **测试**：1 条恒红的部署体检，把真实健康度长期标成"红"，训练大家忽略这条信号。
- **前端**：`client/src/api/modules/security.ts:143 getBuiltinRules` 已定义，**全仓 0 个页面调用**（grep 全仓仅命中定义处）。
  → 当前用户看不到空面板；一旦有人接上就是空页。上一轮我说"内置规则面板恒空"，**这句要更正**：面板不存在，恒空的是接口本身。
- **安全治理可见性**：控制台能看能改的只有 commands(125)/global-rules(8+custom)/evasion(11)；
  旧引擎的 **28 条规则 + 开关 + 自定义规则**在控制台上不可见、不可写。
  实际运行时**两套都在跑**（shell 走统一引擎，其余工具走旧引擎），管理员只看到一半。
- **认知风险**：`dangerous_shell_commands.yaml` 与 `tool_guard.yaml` 都是活规则源，命名与端点语义都不区分来源。

## 5. 解决方案

### A. 最小止血（1 文件，10 分钟）
把 `tool_guard.py:325` 改为读统一源（`global_rules` + `access_control.custom_rules`）。
- 结果：10 条 → 测试阈值 `>=20` 需同步改成 `>=8`
- 遗留：旧引擎 28 条仍不可见；开关/自定义规则仍不生效

### B. 单一真源 + 全量视图（推荐，3 文件 + 1 测试）
1. `builtin-rules` 返回**运行时真实生效的并集**，每条带 `source` 字段：
   `unified.global_rules(8)` + `unified.custom_rules` + `legacy.dangerous_shell_commands(28)` + `unified.commands(125)` 摘要
   → 前端 `ShellRule.source?: "builtin"|"custom"` 字段已存在（security.ts:126-127），可直接复用
2. 删除 3 处假实现：`shell-guard/rules` GET/PUT（读写不存在的 `rules` 键）、`_reload_engine()` 死函数
3. 删除 `config.py` 里不可达的 builtin-rules 处理器（整块 tool-guard 端点标注 deprecated 或移除）
4. 开关语义收口：统一引擎读 `access_control.enabled`（1 处），让控制台开关真正生效
5. 测试阈值保持 `>=20`（并集后约 161 条）

### C. 彻底合并（2-3 人日）
退役旧引擎，28 条规则并入 `tool_guard.yaml`（`migrate_to_unified.py` 已存在），单引擎/单源/单 API。
风险：旧引擎覆盖非 shell 工具（file guardian 等路径级检查），迁移需逐条验证，不能一把梭。
