## 二、P0 逐条证据

### 1. 「选中文件夹 = 工作路径」未实现

设计（`design/file-selection-semantics.md`）第 5-8 行明确：

> 选中文件夹 → **工作路径**：设置对话的工作目录；AI 可以访问这个文件夹下的文件

实现：
- `server/coapis/app/runner/runner.py:1592-1609` 只把目录拼成提示词（"用 glob_search 列目录"），**从不设置工作目录**。
- 全仓 `set_current_workspace_dir` 调用点只有 4 处：`runner.py:994`（设为 `WORKSPACES_DIR/user_id`）与 `reme_light_memory_manager.py` 3 处（记忆工作目录）。**没有任何一处来自 `selected_files`。**

后果：用户勾选目录后，智能体只是"被告知有个目录"，其 `cwd` 仍是用户工作区根，相对路径工具（`execute_shell_command`、`glob_search` 默认 path）行为与用户预期不一致。

### 2. 数据契约漂移

设计契约（`file-selection-semantics.md:88-104`）：

```json
{ "selected_files": [ { "usage": "auto" } ],
  "selected_folders": [ { "usage": "context" } ] }
```

实现（`client/src/pages/Chat/index.tsx:1484-1489`）：

```ts
selectedFiles.map(f => ({ name: f.name, path: f.path, type: f.type }))
```

- 单一扁平数组，靠 `type: "folder" | "file"` 分流（`runner.py:1587-1588`）。
- `usage` 字段（auto/context/参考/使用）在设计与实现中都不存在——设计文档的"高级模式"（用户指定用途）完全没接线。

### 3. UI 不区分目录与文件

`client/src/components/Chat/ChatInputFooter.tsx:51`：

```ts
...files.map(f => ({ kind: 'file' as const, name: f.name, id: f.id }))
```

- `FileInfo` 有 `type: 'file' | 'folder'`（`components/Chat/types.ts:15-19`），**被完全忽略**。
- `CHIP_ICON` 只有 `file/knowledge/session` 三种（第 30-34 行），目录芯片显示为 `FileOutlined`。
- 设计要求的分组展示（`📁 1 个工作路径` / `📄 2 个文件`，`file-selection-semantics.md:130-140`）不存在。

后果：用户勾了一个目录，输入框下方显示的和文件一模一样的芯片，无法分辨"工作路径"和"文件引用"。

## 四、P2 消费链缺口

### 文件"自动读取"降级为"给路径"

设计（`file-selection-semantics.md:11-14`）：选中文件 → **AI 会自动读取文件内容作为背景信息**。

实现：
- 前端把文件拼成 `file://` 附件（`Chat/index.tsx:1465-1473`）。
- 后端 formatter（`agents/model_factory.py:335-349`）把 file block 转成**纯文本占位符**：
  `File 'x' is available at: /path` —— **内容不进模型**。
- 唯一的"读取"约束是提示词（`runner.py:1627`："请使用 doc_reader 工具读取"），属软约束，模型可不调用。

### 社区版知识库引用零消费

- `console.py:393-397` 把 `knowledge_bases` 透传进 meta，注释写明"社区版自身不消费；企业版插件在查询前检索"。
- `runner.py:1658-1666` 的 `enrich_chat_context` 钩子前置条件是 `is_enterprise_installed()`。
- 结论：**社区版用户勾选知识库 = 完全无效果**（无检索、无提示词、无引用）。
- 文档级勾选被显式禁选（`cascadeAdapters.ts:208` `selectable: false`，注释"文档级引用后端尚无消费者"）—— 这条是明确决策，不算偏离。
