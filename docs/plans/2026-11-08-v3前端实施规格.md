# v3 知识沉淀 · 前端实施规格（给子代理）

权威仓库：`/apps/ai/tool-dev/dev-coapis/coapis-agent`（**只准在这个目录里改**）
前端源码目录：`client/src`（构建产物 `client/dist`）

## 背景（一句话）

后端已把"知识沉淀"真相层收敛到 `memories` 表并开了 4 个接口；前端要给用户
两个入口：**聊天里"记下来"** 和 **进化中心里的沉淀治理（可见+可撤销）**，
外加 **引用溯源卡片显示本轮注入的记忆**。

## 后端接口（已实现，勿改后端）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/memory/notes` | body `{content, session_id?, agent_id?, category?}` → `{ok, id, detail}` |
| GET | `/api/memory/knowledge?scope=all&include_archived=true&limit=50&offset=0` | → `{ok, items[], total, stats}` |
| POST | `/api/memory/knowledge/{id}/undo` | 撤销（软删）→ `{ok, id, state:"revoked"}` |
| POST | `/api/memory/knowledge/{id}/restore` | 恢复 → `{ok, id, state:"active"}` |

`items[]` 每项字段（扁平，已定）：
`id, scope("user"|"workspace"|"agent"|"system"), user_id, agent_id, session_id,
category, title, content, importance(0~1), source("timeline"|"user_note"|"promote_shared"|...),
created_at(epoch秒), updated_at, deleted_at(null=活跃), archived(bool)`

引用溯源卡片：后端会在 completed 事件的 `citations[]` 里追加
`{kind:"memory", kb_id:"", resource_id:"memory:<id>", doc_title, snippet, relevance}`。
