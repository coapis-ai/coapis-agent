### 先澄清一件你已经落地的事

**常驻右侧资源栏在 v1.2.28 已经删掉了**（提交 4a75094，净删 1072 行，生产 4890 实测通过）。
今天界面上**没有任何右侧常驻列表**——左栏 300px 是唯一的常驻侧栏。

现在"右边那个东西"是一个**可拖拽浮窗**：默认 760×620，锚主内容区，只有点「查看全部」才出现，关掉即无。
所以真问题不是"要不要右栏"，而是**"这个浮窗要不要留"**。

## 三条实测风险（都是这轮查出来的真数据）

1. **生产资源主表 17 列里没有"定稿"列**，状态实测只有 `draft(60)/deleted(35)/orphan(21)`——**零 active、零 official**。
   → 左栏"定稿徽标"在生产**现在无数据可显示**；要做得先补列＋迁移（约 0.3 人日）。
   这与知识库"晋升 0 条"是**同一件事的两面**：定稿链路本身没跑通，徽标只是它的显示端。
2. **台账来源字段实测值域 = `write_file(121)/reconcile(120)/edit_file(73)/upload(13)`**，
   与前端"上传／智能体生成／知识库引用／聊天导入"四类**不是同一套词**。
   → 来源口径必须以服务端字段为准，前端停止自行推导（这正是"台账口径单一化"的内容）。
3. **生产 schema 落后于代码**（迁移级别 0025），且本轮实测到**沙箱内 docker 视图与宿主不一致**：
   同一容器名先后读出两套列定义。→ 生产升级前须在宿主侧核对迁移级别，不能只信沙箱读数。
