## 〇、本轮先做一次更正（重要）

v2 方案里的文件名、行号、组件名取自子代理调研，**与真实代码对不上**。本轮已逐个实证，本版全部换成真实路径与行号。两处结论因此改变：

1. 右栏组件真名是 `CoApisResourceStrip`（不是 ChatRightPanel），在聊天页里以「会话条 + 聊天条」两条并排的形式挂载。
2. v2 说的「跨聊天台账表，保留要补写/补读，0.15 人日」——**代码里不存在这张表**。跨聊天汇总是后端接口现成的作用域参数（scope=session），前端只是显示层。跨聊天砍掉＝前端不再请求该作用域，**零新增工作**，v2 那 0.15 人日作废。

已实证的关键事实（决定了改法）：

- 左栏展开态存 sessionStorage，键 `coapis.chat.sidebarExpandedId`，初值取不到就是 `null`＝**首屏收起**（ChatSessionDropdown 约 349–352 行）。
- 同文件约 386–395 行已有「切会话/新建即自动展开」的跟随逻辑——**切会话本来就展开，只有首屏是收起**。改动只需补首屏与首条消息这一段。
- 同文件约 368–375 行的持久化逻辑：收起时 `removeItem` 抹掉记录，刷新后又被当回首屏默认——这就是「收起后一刷新又展开」的成因，必须用哨兵修。
- 左栏展开面板只请求当前聊天（scope=chat），**天然没有跨聊天汇总**，符合拍板 2。
- 右栏上半区才是跨聊天（scope=session），删右栏＝该作用域前端零调用者。

### 任务 C｜左栏当前会话行默认展开（0.35 人日）

改 `ChatSessionDropdown/index.tsx` 三处，约 +12/−3：

1. **初值**（约 349–352）：读 sessionStorage；读到哨兵 `__collapsed__` → 收起；读到具体会话号 → 展开该行；**读不到（首次进入）→ 置为「未定」标记**，交由下一步落地。
2. **首条消息即展开**（新增 1 个 effect）：处于「未定」且当前会话已产生第一条消息（沿用聊天页已有的会话列表/消息计数，不新增接口）→ 把展开位落到当前会话。空会话保持收起，首屏干净。
3. **收起写哨兵**（约 368–375 持久化处）：收起时改写哨兵值而不是删除记录；显式展开时清除哨兵，恢复自动跟随。
   - 语义：用户手动收起＝对该会话永久尊重，刷新不反弹；切会话/新建仍自动展开（已有行为，不动）。
4. 跟随逻辑（约 386–395）保持原样——它只处理"切换会话"，与初值互不干扰。

## 四、验收清单（13 条）

**右栏下线**
1. 聊天页右侧无资源列表，聊天区独占至窗口右边缘。
2. 1280px / 1024px / 820px 三档窗口下，输入区与「知识库」按钮无遮挡、可点击。
3. 浏览器窗口极窄（<520px）时不再出现 40px 图标条或空白竖栏。
4. 气泡末尾「本轮资源条」正常：引用/产出分组、超 8 条折叠为「展开其余 N 项」、尾部「查看全部」可开抽屉。
5. 会话回放（刷新后重进旧会话）资源条照常显示，不丢条目。

**左栏默认展开**
6. 全新浏览器首次进入：空会话收起；发出第一条消息后当前会话行自动展开并出现资源行。
7. 切会话／新建会话：展开位自动跟到新会话（原有行为不变）。
8. 手动收起当前会话后刷新：保持收起，不反弹。
9. 收起 A 会话再切到 B 会话：B 展开；切回 A 保持收起。
10. 左栏宽度 300px 下，收起按钮、搜索、新建按钮不挤压换行。

**跨聊天**
11. 界面上不出现「当前会话/当前聊天」两级汇总；抽屉只有当前聊天一份清单。
12. 左栏「查看全部 · N」计数＝当前聊天条目数，与展开面板一致。

**兜底**
13. 全程无新增控制台报错；社区/企业双入口构建通过；预览浮窗（md 完整渲染 / pdf 保真 / 图片内联 / Office 三件套转大纲）行为不变。

## 五、风险与对策

| 风险 | 对策 |
|------|------|
| 右栏删除后，老用户找不到「跨聊天」资源入口 | 会话本体在左栏列表可见，逐会话资源在展开面板与抽屉可查；如需一次性看全部，走「我的空间」文件列表（社区版已有） |
| 展开面板占高，长会话列表可见行数减少（约 8 → 5.3 行） | 面板上限 40 条 + 可滚动；列表本身独立滚动，会话多时不受影响 |
| 哨兵标记与既有 sessionStorage 值冲突 | 哨兵用独立字符串，读到旧值（会话号）照旧生效；用户清浏览器站点数据即回默认 |
| `LiveResource` 类型搬家漏引用 | 类型检查会直接暴露；搬家后跑一次全量 tsc |
| 语言包删键被别处引用 | 已 grep 实证仅 `CoApisResourceStrip` 与抽屉标题两处使用，均在删除范围内 |
